## 1. What is Anclora EnergyScan

![Home page in dark mode](screenshots/imagen-pag3-en.png)

**Anclora EnergyScan** is a platform for organising the energy information of a home before making decisions: renovating, comparing quotes, requesting provider contact, or preparing for a technical visit.

The tool generates an **indicative estimate** based on data declared by the user and, when provided, on documents such as photographs, cadastral references, certificates or renovation quotes.

### What you can do

| Profile | What it allows |
| --- | --- |
| Residential user | Create a pre-assessment, view history, download the free PDF, unlock the Premium PDF and analyse renovation quotes |
| Professional | Manage client files from a professional account. Example: a real estate agency preparing indicative reports for properties in its portfolio |
| Provider | Receive consented commercial opportunities. Example: an EPC issuer, windows company, solar, insulation, HVAC or renovation contractor |

The same organisation can use more than one profile. For example, a technical firm can use the professional area to prepare client files and also register as a provider to receive commercial requests. EnergyScan shows both profiles as independent access points.

### Improvements included in this version

This edition of the manual incorporates the most recent connected surfaces of the application:

| Area | Improvement visible to the user |
| --- | --- |
| Residential dashboard | KPIs, assessment history, Premium status, renovation quotes, provider/professional access and next steps |
| Free result | Downloadable 2-page basic PDF and a viability block if you have indicated a target energy class |
| Premium Report | Access to the PDF from the result page or from the dashboard once payment is confirmed |
| AI visual analysis | In Premium, uploaded photographs can generate a page of indicative visual observations |
| Budget Review | Quote history with status, detected total and action to open or unlock the full analysis |
| Beta professional | Access request, review statuses and initial case dashboard |
| Provider | Operational dashboard with credits, leads, blocked contact, traceable unlocking and commercial tracking |

The screens shown have been updated with the connected version of EnergyScan, maintaining the premium dark/light style and the main application navigation where applicable.

### What EnergyScan does not do

- It does not issue official Energy Performance Certificates.
- It does not replace recognised software or a visit by a qualified technician.
- It does not guarantee savings, costs, grants, works or commercial outcomes.
- It must not be used as an administrative document.

## 2. Before you start

### Recommended requirements

For a more useful estimate, have the following to hand:

- Property type: flat, detached house, terraced house or other.
- Approximate year of construction.
- Approximate floor area.
- Postcode or address.
- Heating, cooling and hot water systems.
- Condition of windows, façade and roof.
- If available: photographs, cadastral reference, a previous EPC or a renovation quote.

### How to interpret the results

| Element | Meaning |
| --- | --- |
| Estimated class | A-G approximation of the energy situation |
| Confidence | Reliability level based on data quality and quantity |
| Penalties | Factors that may worsen the result |
| Strengths | Favourable data points detected |
| Scenarios | Possible improvement paths — always indicative |

> If you intend to sell, rent, apply for grants or register an official rating, you will need an EPC issued by a competent technician.

## 4. Residential use step by step

### 4.1 Home page

![Full home page](screenshots/imagen-pag8-en.png)

The home page summarises the main actions:

1. **Start assessment**: opens the pre-assessment wizard.
2. **View pricing**: shows the free, Premium and professional plans.
3. **Product**: expands access to the calculator, renovation quotes, providers and professional area.
4. **Preferences**: changes language, theme, currency and units.

### 4.2 Energy savings calculator

![Energy savings calculator](screenshots/imagen-pag9-en.png)

The calculator is public and quick. It is useful for estimating general ranges before carrying out the full assessment.

**Steps:**

1. Select the property type.
2. Enter the floor area.
3. Enter the approximate monthly energy cost.
4. Select the measures you are interested in.
5. Click **Calculate indicative range**.

| Result | How to read it |
| --- | --- |
| Annual savings | Possible savings range — not guaranteed |
| Indicative cost | Approximate investment for the selected measures |
| Payback | Approximate return period in years |

### 4.3 Pre-assessment wizard

![Pre-assessment wizard](screenshots/imagen-pag10-en.png)

The wizard is the main flow for creating a new assessment. It consists of 5 guided steps that can be completed in a few minutes.

| Step | What to provide |
| --- | --- |
| Objective | Know current status, renovate, sell/rent or another goal |
| Property data | Type, year, floor area and postcode |
| Orientation and roof | Data that influences thermal demand |
| Systems | Heating, cooling, hot water, ventilation and renewables |
| Building envelope | Windows, façade insulation and roof insulation |
| Timeline and budget | Planned timeframe and financial range |
| Documentation | Photographs, EPC or renovation quote to enrich the assessment |

### 4.3.1 Target energy class selection

![Target energy class selection](screenshots/imagen-pag11-en.png)

If you choose **Reach a specific class**, the wizard displays an A–G class selector. You can indicate which class you want to achieve and the assessment will consider whether it is feasible given the data you enter. EnergyScan will show a notice if the target is very ambitious or if you already meet it with your current situation.

### 4.4 Cadastral search and property map

![Property data with cadastral search and map](screenshots/imagen-pag12-en.png)

In the property data step you can use the **Cadastral Search** to locate the property by cadastral reference or address. The map updates automatically and allows you to select the exact location. Data obtained from the Cadastre (floor area, year of construction, type) is pre-filled in the form to speed up the process. You can also submit documents or images in this step.

**Good practices:**

- Review the imported data before continuing.
- Do not upload documents unrelated to the property.
- Avoid including unnecessary personal data in photographs or renovation quotes.
- If you import an EPC and the current class already meets or exceeds your target, the wizard will show an amber notice to review the goal and suggest a more ambitious class.
- The photograph progress bar only appears when there are images in the upload queue. If you upload documents only — such as an EPC or renovation quote — this bar is not shown.

### 4.5 Free result

After completing the wizard you will see the preliminary result:

- Estimated energy class.
- Confidence level.
- Climate zone.
- Captured data.
- Penalties, strengths and missing data.
- Preview of Premium content.
- Free basic PDF download if the assessment is not a demo.
- Amber banner if you have uploaded photographs and have not yet unlocked Premium.

![Target class viability](screenshots/assessment-target-viability-dark.png)

If you selected **I want to reach a specific class**, EnergyScan shows a viability block before the paywall. It may indicate:

| Scenario | What it means |
| --- | --- |
| Target achievable within budget | The minimum estimated cost falls within the declared budget |
| Target achievable but above budget | The improvement is possible, but the indicative investment exceeds the stated budget |
| Target not achievable | Even a full renovation estimate would not reach the target class |

The amounts are indicative and do not replace a real technical quote.

![Photographs saved as evidence banner](screenshots/assessment-photos-premium-banner-dark.png)

If you have uploaded photographs, they are kept as evidence. The AI visual analysis of those images is reserved for the Premium report.

![Free PDF download](screenshots/assessment-free-pdf-dark.png)

The free PDF includes 2 pages with the estimated class, climate zone, confidence level and main weaknesses and strengths. It does not include full scenarios, costs, grants, AI visual analysis or a premium annex.

From the result page you can:

| Action | When to use it |
| --- | --- |
| View result | Review the basic assessment |
| Download free PDF | Save a 2-page basic summary at no cost |
| Unlock Premium | Get full scenarios and the full PDF |
| Analyse quote | Move on to the second opinion on a renovation quote |
| Request a provider | Share data with selected providers when consent exists |
| Back to dashboard | Retrieve history and actions |

## 6. Premium Report and payments

![Pricing page](screenshots/imagen-pag19-en.jpeg)

The **Premium PDF Report** is a one-time paid product for a specific assessment.

### 6.1 What it includes

| Section | Content |
| --- | --- |
| Full assessment | Class, confidence, context and main factors |
| Improvement scenarios | Recommendations grouped by priority |
| Indicative costs | Ranges by item or measure |
| Regulatory context | EPBD context and indicative risks |
| Grants / subsidies | Informative references — not a guarantee of approval |
| Document annex | Submitted data and available traceability |
| Cadastral images | Highlighted plot diagram and cartographic map of the surroundings when cadastral data is available |
| AI visual analysis | Final page with observations on up to 3 submitted photographs, if available |

### 6.2 Free vs Premium comparison

| Feature | Free | Premium |
| --- | --- | --- |
| Indicative result on screen | Yes | Yes |
| Estimated class and confidence | Yes | Yes |
| Downloadable PDF | Basic 2-page PDF | Full professional PDF |
| Improvement scenarios | Preview | Full detail |
| Indicative costs | No | Yes |
| Grants and extended regulatory context | No | Yes |
| AI visual analysis of photographs | No | Up to 3 photographs prioritised by energy relevance |
| Cadastral images in PDF | No | Highlighted plot and surroundings map if data is available |

### 6.3 Free PDF

The free PDF is available from the result page at no cost, as long as the assessment is not a demo. It is useful for saving a basic summary or sharing an initial reading.

It includes:

- Estimated energy class.
- Climate zone.
- Confidence level.
- Main weaknesses detected.
- Main strengths.
- Premium invitation block.

It does not include full scenarios, indicative costs, grants, AI visual analysis, document annex or cadastral images.

### 6.4 AI visual analysis of photographs

If you unlock Premium and have uploaded photographs, EnergyScan can automatically analyse up to 3 images, prioritising façades and window frames for energy relevance.

| Plan | Images analysed |
| --- | --- |
| Free | 0. Photographs are kept as evidence |
| Premium | Up to 3 |
| Pro / B2B | Ready for up to 8 — not active for end users in this version |

The analysis appears in the Premium PDF as an **AI visual analysis of submitted images** page. It groups findings by category, proposes verifications for a technician and shows limitations. The language is measured: it uses expressions such as "it appears", "this could correspond to" or "seems to feature", never conclusive statements.

> AI visual analysis does not constitute an energy certificate, does not replace a site visit or technical inspection, and may be limited by the quality, framing or content of the photographs.

### 6.5 How to unlock it

1. Complete an assessment.
2. On the result page or in the dashboard, click **Unlock Premium**.
3. Review the Stripe checkout.
4. Complete payment by card in secure mode.
5. Return to the result page or dashboard.
6. Click **Download PDF**.

### 6.6 Payment statuses

| Status | Meaning |
| --- | --- |
| Free | The assessment exists but Premium has not been unlocked |
| Payment pending | Checkout was started but confirmation is still pending |
| Premium | Payment is confirmed and the PDF is available |
| Demo | Authorised sample mode |

> If you have just paid and the status still shows as pending, wait a few seconds and reload the page. Confirmation depends on the Stripe webhook.

## 7. Second opinion on a renovation quote

![Second opinion on a renovation quote](screenshots/imagen-pag23-en.jpeg)

The second opinion analyses a renovation quote to detect line items, amounts and possible alerts.

### 7.1 When to use it

Use it before accepting a quote for:

- Windows.
- Insulation.
- Heat pump or HVAC systems.
- Photovoltaic installation.
- Full energy renovation.

### 7.2 Accepted formats

| Format | Example |
| --- | --- |
| Pasted text | Copied from email, Word or PDF |
| Text-based PDF | Quote exported from a word processor |
| Tables | Excel/LibreOffice exported to PDF |
| Lists | Quotes with bullet points or chapters |
| Works codes | Presto/Arquimedes-style formats if the text is readable |

### 7.3 Free result

The free result shows:

- Number of line items detected.
- Detected total.
- Analysis confidence.
- General alerts.

### 7.4 Full report

The full report is independent of the residential Premium and has its own payment.

It includes:

- Line item review.
- Possible out-of-range prices.
- High quote alerts.
- Indicative observations.

> It does not replace a review by a qualified technician, architect, quantity surveyor, legal adviser or contractor following an on-site measurement.

### 9.2 Provider registration

![Provider registration](screenshots/imagen-pag29-en.jpeg)

To register:

1. Go to **Providers**.
2. Click **Register as provider**.
3. Complete company name, email, phone, website, categories and service areas.
4. Submit the form.

| Field | Advice |
| --- | --- |
| Categories | Use clear codes: HVAC, SOLAR, WINDOWS, INSULATION, CEE |
| Service areas | Indicate real commercial areas: Palma, Mallorca, Balearic Islands |
| Email | Use an operational email address for notifications |

The provider may be in statuses such as **PENDING**, **VERIFIED**, **PREFERRED**, **SUSPENDED** or similar, subject to internal review.

After submitting the form, Anclora reviews the profile internally. When the status changes to **VERIFIED** — or a higher status — you will receive a notification at the email address provided. To access your provider dashboard, create an account or sign in to EnergyScan using that same email address: the link is made automatically on first access.

### 9.5 Blocked contact and unlocking

For privacy reasons, personal data is blocked initially:

| Before unlocking | After unlocking |
| --- | --- |
| Name not shown | Name shown if available |
| Email not shown | Email shown |
| Phone not shown | Phone shown |
| No credit consumed | Credit consumption recorded |

To unlock:

1. Review the technical context of the lead.
2. Check that you have credits.
3. Click **Unlock contact**.
4. 1 credit is consumed.
5. The contact becomes visible.
6. Consumption is recorded in the ledger.

If you have already unlocked that lead, opening it again does not consume another credit.

### 9.6 Changing commercial status

On each lead you can update the status:

| Status | Recommended use |
| --- | --- |
| Pending | New or unreviewed lead |
| Contacted | You have already contacted the user |
| Quote sent | You have sent a renovation quote |
| Won | Work is closed |
| Lost | Not closed |
| Cancelled | Request discarded |

### 9.7 Credits and billing

![Provider credits](screenshots/imagen-pag33-en.jpeg)

| Element | Description |
| --- | --- |

## 11. Frequently asked questions

**Does EnergyScan issue official certificates?**

No. EnergyScan only generates indicative pre-assessments. The official EPC must be issued by a qualified technician.

**Is the free result sufficient to sell or rent a property?**

No. To sell or rent you need an official EPC when applicable regulations require it.

**What is the difference between the free result and Premium?**

The free result shows a basic estimate and allows downloading a 2-page basic PDF. Premium adds a full PDF, scenarios, costs, extended context, grants, cadastral images and AI visual analysis of photographs if you have submitted them.

**Does the free PDF replace the Premium report?**

No. The free PDF summarises the indicative class, confidence level and main findings. It does not include full scenarios, costs, grants, AI visual analysis or a document annex.

**What does AI visual analysis do?**

It reviews up to 3 submitted photographs in an indicative way within Premium. It can point out signs relating to the façade, windows, roof, heating, insulation or interiors, but it does not replace a technician's inspection.

**Why does a notice appear about my target class?**

If you select a target class, EnergyScan may indicate whether it appears achievable, whether it requires more budget than declared, or whether it does not appear technically achievable under current rules. It is an estimate, not a quote.

**Is Budget Review included in Premium?**

No. It is an independent product for analysing renovation quotes.

**Can I retrieve my assessments?**

Yes, if you made them while signed in. They are in the dashboard.

**Can I change the language or theme?**

Yes. Use the preferences selector in the top bar.

**What happens if a payment shows as pending?**

Wait a few seconds and reload. Stripe confirms payment via webhook.

**Can a provider automatically see my phone number?**

No. Only when a consented request exists and the provider unlocks the contact.

**Are providers guaranteed by EnergyScan?**

No. A verified or preferred status may indicate internal review, but does not guarantee works, pricing, savings or any outcome.
